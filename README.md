# FORMA — мебель по месту

Локальный portfolio concept лендинга для условной компании по изготовлению корпусной мебели на заказ. Концепт создан GrayCatStudio на основе реального типа фриланс-заказа: продающий сайт без онлайн-оплаты, корзины и личного кабинета, с акцентом на заявку и консультацию.

## Цель

Показать потенциальному заказчику, как может выглядеть коммерческий лендинг для кухонь, шкафов, гардеробных и другой корпусной мебели по индивидуальным размерам.

## Стек

- HTML5 с семантическими секциями;
- CSS без фреймворка: Grid, Flexbox, адаптивные `clamp()`-размеры и CSS-анимации;
- vanilla JavaScript для меню, reveal-анимаций, навигации и demo-формы;
- локальные SVG-fallback и JPEG-фото-референсы без внешних библиотек;
- источники изображений зафиксированы в `docs/assets-sources.md`.

## Как запустить локально

Из PowerShell:

```powershell
Set-Location 'D:\GreyCatStudio\Furniture-Landing'
py -m http.server 8080 --directory .
```

Откройте в браузере: <http://localhost:8080>

Остановить сервер можно сочетанием `Ctrl+C`.

## Текущий статус

Готов локальный статический portfolio concept с полноценной desktop/mobile-структурой, основными конверсионными секциями, адаптивным меню, локальной demo-формой и реальными интерьерными фото-референсами. Фото используются только как демонстрационный визуал, а не как портфолио выполненных объектов этой концептуальной компании. Tilda, backend, отправка данных и публикация не подключались.

## Что является demo content

- бренд FORMA и весь текст о компании — вымышленная концепция;
- пять локальных JPEG-фото из Pexels используются как фото-референсы и демонстрационные направления;
- источники, страницы авторов и проверенная лицензия перечислены в [`docs/assets-sources.md`](docs/assets-sources.md);
- прежние SVG-визуализации сохранены в `assets/images` как неиспользуемый fallback и не удалялись без необходимости;
- номер телефона в шапке и footer — placeholder `+7 000 000-00-00`;
- упоминания Telegram / WhatsApp требуют замены на реальные ссылки;
- success state формы локальный: данные не отправляются и не сохраняются;
- блок доверия намеренно не содержит фальшивых отзывов, рейтингов и реальных кейсов.

## Перед production deployment

1. Заменить бренд, контакты, мессенджеры, юридическую информацию и фото-референсы на подтверждённые материалы клиента.
2. Подключить согласованный endpoint формы, webhook или Tilda Forms и добавить актуальную политику обработки данных.
3. Уточнить реальные условия оплаты, доставки, монтажа, гарантии и сроки.
4. Перед production повторно проверить условия лицензии выбранных стоковых фото либо заменить их на реальные материалы бизнеса.
5. Провести финальную проверку на целевых устройствах и заменить demo-пометки там, где контент станет подтверждённым.
